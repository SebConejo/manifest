## Critical Bug Found and Fixed

`rebuild_csv.py` was reading `data.get("score")` (V1) instead of preferring
`data.get("judge_v2_score")` (V2). This caused all V3 analyses to run on V1
scores when reproducing from scratch. Fixed by changing line 153 to:
```python
score = data.get("judge_v2_score") or data.get("score", 0) or 0
```

Also fixed stale prices for gpt-5.5-pro ($5/$20 → $15/$75), gpt-5.4
($2/$8 → $1/$4), gpt-5.1-chat ($2/$8 → $0.80/$3.20) in the MODELS dict
inside rebuild_csv.py.
